## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mohindrooparth-byte/NEW_PORTFOLIO.git
   cd NEW_PORTFOLIO
   ```

2. **Open directly in browser**:
   * Double click `index.html` or open it with your browser:
     ```bash
     open index.html      # On macOS
     xdg-open index.html  # On Linux
     start index.html     # On Windows
     ```

3. **Or serve via Python**:
   ```bash
   python3 -m http.server 8000
   ```
   Visit `http://localhost:8000` in your browser.

## ⚡ How to Deploy on Vercel

### Method 1: Using the Vercel Web Dashboard (Recommended)
1. Go to [vercel.com/new](https://vercel.com/new).
2. Sign in with your GitHub account (**mohindrooparth-byte**).
3. Under **Import Git Repository**, choose `NEW_PORTFOLIO`.
